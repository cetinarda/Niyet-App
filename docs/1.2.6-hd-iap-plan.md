## ⚠️ KRİTİK: 992ab50 koruması consumable'da FARKLI olmalı

- `userInitiatedAction` gate premium için doğru AMA consumable için tehlikeli:
  kullanıcı satın alır → app çöker → slot verilmeden → gate replay'i yutar →
  kullanıcı parasını kaybeder (consumable'da restore YOK).
- **Çözüm:** consumable yolunda `userInitiatedAction` yerine **transactionId

  transactionId → slot ver + finish; görülmüş → sadece finish.
- yearly/lifetime için userInitiatedAction AYNEN kalır (bu yüzden handler
  ürün ID'ye dallanmalı).

## Host ↔ embed köprüsü

- Kaynak: host `localStorage.sakin_hd_slots_available` (integer). Same-origin,
  embed doğrudan görür.
- Embed "+ Yeni Kimlik" (profiles.length >= 1) → postMessage `sakin-hd-slot-request`.
- Host: slot var mı? Yoksa `purchaseHDSlot()` sheet → başarı → sayaç++ →
  `sakin-hd-slot-granted` postMessage.
- Embed profil oluşturur → `sakin-hd-slot-consumed` → host `consumeHDSlot()` (sayaç--).
- Tüketim host-kontrollü (embed bundle'ı minimum değişir).
